# Progetto Arca AI — presentation website

Client-facing narrative website prepared for the presentation of Progetto Arca AI.

The experience connects:

- governed fundraising data and policy-based segmentation;
- executive reporting and drill-down analysis;
- Luma's role-based interpretation and proactive recommendations;
- human review before operational action.

The current version is intended for internal review before the client presentation. It includes authentic Progetto Arca imagery and product screenshots, so the repository and preview should remain private until publication is explicitly approved.

## Local preview

Requirements: Node.js 22.13 or later and pnpm.

```bash
pnpm install
pnpm dev
```

## Validation

```bash
pnpm test
pnpm build
```
